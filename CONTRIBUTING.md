# Contributing to ABridge

## Build from source

Prerequisites: macOS 26+, Xcode 26+, Rust 1.89+, [just](https://github.com/casey/just), [XcodeGen](https://github.com/yonaskolb/XcodeGen), SwiftFormat, and SwiftLint (`brew install just xcodegen swiftformat swiftlint`).

```sh
git clone git@github.com:rcanoff/abridge.git
cd abridge
xcodegen generate
just build-rust
open ABridge.xcodeproj
```

Run the app, start the server from the menu bar, and point your MCP client at the endpoint in the [README](README.md#connect-your-mcp-client).

Local builds are ad-hoc signed, so each rebuild gets a new signature and macOS asks again for Keychain and privacy access. To sign with your development certificate instead, create `Configs/Local.xcconfig` (gitignored):

```
DEVELOPMENT_TEAM = <your team ID>
CODE_SIGN_STYLE = Manual
CODE_SIGN_IDENTITY = Apple Development
```

Choose **Always Allow** at the next Keychain prompt and later rebuilds keep the grant.

## Architecture

Swift owns the UI, permissions, Keychain, and thin Apple framework adapters. Rust (`abridge_core`, bridged with UniFFI) owns the MCP/HTTP server, auth, routing, response shaping, fuzzy search, and the whole Notes provider. See the [architecture guide](docs/architecture-bootstrap-guide.md).

|Path|Contents|
|---|---|
|`ABridge/`|SwiftUI app, stores, services, Apple framework adapters|
|`ABridgeTests/`|Swift Testing unit tests|
|`rust/abridge_core/`|MCP/HTTP server, auth, routing, Notes provider, Rust tests|
|`ABridgeCore/`|Generated by `just build-rust`; not committed, never edited|
|`icon/`|App mark sources: SVG, Icon Composer, README images|
|`project.yml`|XcodeGen source; run `xcodegen generate` after editing|
|`docs/`|PRD, conventions, architecture guide|

## Commands

|Command|Purpose|
|---|---|
|`just ci` (alias `just preflight`)|Full local CI: Rust and macOS steps|
|`just ci-rust`|Rust fmt, clippy, and tests|
|`just ci-macos`|SwiftFormat, SwiftLint, UniFFI build, and Swift tests|
|`just test-rust` / `just test-swift`|Run one test suite|
|`just lint-rust` / `just lint-swift`|Lint one side|

GitHub workflows run on `workflow_dispatch` only, so run `just preflight` before pushing. Permission dialogs, interactive Keychain prompts, and end-to-end MCP sessions are tested by hand.

## Pull requests

- Branch as `feat/<short-description>` or `chore/<short-description>`, one concern per branch.
- Install the hooks: `git config core.hooksPath .githooks`.
- Run `just preflight` before opening a PR.
- Follow [docs/conventions.md](docs/conventions.md) for naming, formatting, errors, and tests.

Agent rules, the full command list, and release steps live in [AGENTS.md](AGENTS.md). By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
